# Delta Exchange India コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Delta Exchange India コネクター**は、StockSharp をインドの中央集権型デジタル資産デリバティブ取引所へ接続します。先物・オプションの市場データ、注文、口座状態を標準の StockSharp メッセージモデルへ変換します。

## 主な機能

- Delta Exchange India に上場する先物・オプションの検索と参照データ取得。
- REST による Level 1 スナップショットと WebSocket によるリアルタイム更新。過去の Level 1 イベントには対応していません。
- REST による直近の約定履歴（1 リクエスト最大 50 件）と WebSocket によるライブ約定。
- 最大 15 階層の板スナップショットとライブ更新。差分板および過去の板には対応していません。
- 1 リクエスト最大 1,999 本の過去ローソク足と、プロバイダー対応時間枠のライブ更新。
- 指値、成行、条件付きストップ注文、post-only、reduce-only、注文変更、取消、一括取消。
- 認証済み REST API とプライベートストリームによるポートフォリオ、残高、ポジション、注文、約定の更新。

## 主な用途

Delta Exchange India の直近約定やローソク足履歴を必要とするリアルタイムのデリバティブ戦略、取引端末、注文管理サービス、分析システムに使用できます。

プライベート操作には API 認証情報と必要な口座権限が必要です。利用可能な商品、履歴範囲、リクエスト制限、地域別の提供状況はプロバイダーに依存します。アイスバーグ注文、絶対有効期限、一括ポジション決済は実装されていません。
