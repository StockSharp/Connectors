# Коннектор Dukascopy JForex

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Dukascopy JForex** подключает StockSharp к Dukascopy Bank через официальный Java SDK JForex. За защищённую авторизованную сессию с торговыми серверами Dukascopy отвечает сам SDK, а .NET-адаптер обменивается с ним командами и событиями через локальный bridge.

## Основные возможности

- Получение списка валютных пар, CFD, металлов, индексов, сырьевых товаров, облигаций и других доступных счёту инструментов.
- Котировки Level 1, тиковые сделки, изменения стакана и свечи по временным интервалам.
- Исторические тики и свечи через сервис истории JForex.
- Рыночные, лимитные, стоп-, стоп-лимитные и специальные команды заявок JForex.
- Регистрация, изменение и снятие заявок, обновления исполнений, баланса и позиций.
- Раздельные настраиваемые адреса сервисов JForex для demo- и live-режимов.
- Bridge можно запускать из указанного исполняемого JAR либо держать отдельным локальным процессом.

## Схема работы

Для работы требуется Java, поскольку Dukascopy публикует и поддерживает JForex именно как Java API. Включённый Maven-проект bridge использует официальный пакет `DDS2-jClient-JForex`. Bridge слушает только loopback-интерфейс компьютера и не выставляет учётные данные счёта в сеть.

Коннектор подходит для торговых роботов, терминалов, мониторинга и сервисов управления заявками, которым нужен стандартный интерфейс сообщений StockSharp. Доступные инструменты, глубина истории и стакана, а также торговые права зависят от подключённого счёта Dukascopy.
