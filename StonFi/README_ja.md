# STON.fi コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**STON.fi コネクター**は、StockSharp を STON.fi 流動性プールと TON ブロックチェーンへ接続します。設定または検出したプールを銘柄として表し、スワップ見積もり、プールイベント、ウォレット残高、送信済みスワップを StockSharp メッセージへ変換します。

## 主な機能

- 設定済みプールまたは件数を制限した人気 STON.fi プールをトークン情報とともに検出。
- 実行可能なスワップシミュレーションから Level 1 の売買価格を算出し、ポーリングで更新。
- TON プールイベントから履歴・ライブのティック取引を取得し、スワップから期間別ローソク足を構築。
- TON Wallet V4 のニーモニック、設定可能なスリッページ、TON Center 送信による即時成行スワップ。
- ウォレットのトークン残高と、スワップの注文・約定状態を追跡。
- 履歴は設定した TON ブロック範囲に制限され、ライブ配信はポーリングに依存。
- 中央集権型の板、待機する指値注文、変更、取消は提供しない。
- REST データ、TON 単位、ウォレット署名、チェーンイベントは標準 StockSharp API の背後に隠蔽。

## 主な用途

TON DEX の価格監視、プール分析、スワップ戦略、ウォレット追跡、STON.fi での直接執行に利用できます。

プール範囲、価格品質、履歴、経路、手数料、確定性、可用性は STON.fi、TON Center、設定エンドポイント、チェーン状態に依存します。
