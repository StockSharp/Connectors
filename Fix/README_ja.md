# FIX プロトコルコネクター

**FIX プロトコルコネクター**は、設定可能な Financial Information eXchange セッションを通じて StockSharp をブローカー、取引所、取引システムへ接続します。方言固有のメッセージを統一 StockSharp メッセージモデルへ対応付けます。

## 主な機能

- 複数のブローカー、取引市場、セグメント向けの設定可能な FIX 方言。
- セッションログオン、認証、ハートビート、シーケンス追跡、再送、再接続、任意のセキュア通信。
- 方言が対応する銘柄検索、Level 1、取引、板情報、ローソク足、ニュース、注文ログイベント。
- 相手先が対応する注文送信、変更、取消、一括取消、ステータス照会、約定処理。
- トランザクションセッションのポートフォリオ、残高、ポジション更新。
- 標準 StockSharp 設定モデルによる送信元、送信先、口座、エンドポイント、セッションの設定。

## 主な用途

独自のブローカー接続、取引所ゲートウェイ、ライブ戦略、注文管理サービス、正規化された市場データアクセスに利用できます。

具体的なメッセージ、フィールド、注文種別、リカバリー動作、権限は、選択した FIX 方言と相手先のセッション仕様によって決まります。
