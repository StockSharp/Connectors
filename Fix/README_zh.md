# FIX 协议连接器

**FIX 协议连接器**通过可配置的 Financial Information eXchange 会话，将 StockSharp 接入经纪商、交易所和交易系统。它把方言特有的消息映射为统一的 StockSharp 消息模型。

## 主要功能

- 为多个经纪商、交易场所和市场板块提供可配置的 FIX 方言。
- 支持会话登录、认证、心跳、序号跟踪、重发处理、重新连接和可选的安全传输。
- 在方言支持时提供交易品种发现，以及 Level 1 行情、成交、订单簿、K 线、新闻和订单日志事件。
- 在对手方支持时提供订单提交、修改、撤销、批量撤销、状态查询和成交处理。
- 为交易会话提供投资组合、余额和持仓更新。
- 通过标准 StockSharp 配置模型设置发送方、目标方、账户、端点和会话参数。

## 适用场景

适用于自定义经纪商集成、交易所网关、实时策略、订单管理服务和规范化市场数据访问。

具体消息、字段、订单类型、恢复行为和权限取决于所选 FIX 方言及对手方的会话规范。
