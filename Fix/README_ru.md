# Коннектор протокола FIX

**Коннектор протокола FIX** подключает StockSharp к брокерам, биржам и торговым системам через настраиваемые сессии Financial Information eXchange. Он преобразует сообщения выбранного диалекта в единую модель сообщений StockSharp.

## Основные возможности

- Настраиваемые FIX-диалекты для различных брокеров, площадок и сегментов рынка.
- Вход в сессию, аутентификация, heartbeat, контроль последовательности, повторная передача, переподключение и опционально защищённый транспорт.
- Поиск инструментов и рыночные данные: Level 1, сделки, стаканы, свечи, новости и события лога заявок, если их поддерживает диалект.
- Выставление, изменение и снятие заявок, массовая отмена, запрос статуса и обработка исполнений, если это поддерживает контрагент.
- Обновления портфелей, средств и позиций для транзакционных сессий.
- Настройки отправителя, получателя, счёта, адреса и сессии через стандартную модель конфигурации StockSharp.

## Для чего подходит

Используйте коннектор для интеграции с брокерами, биржевых шлюзов, живых стратегий, сервисов управления заявками и унифицированного доступа к рыночным данным.

Точный набор сообщений, полей, типов заявок, восстановление и права зависят от выбранного FIX-диалекта и спецификации сессии контрагента.
