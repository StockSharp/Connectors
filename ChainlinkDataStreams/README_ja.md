# Chainlink Data Streams コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Chainlink Data Streams コネクター**は、StockSharp をデジタル資産の市場データ・分析サービスに接続します。 プロバイダー固有のデータと操作を統一された StockSharp メッセージモデルへ変換するため、異なる取引先でも同じ購読とワークフローを利用できます。

## 主な機能

- 主な対象：デジタル資産、FX と CFD。
- 銘柄検索とプロバイダーの参照データ。
- アダプターが対応する市場データ：Level 1 クォート。
- チャート、分析、バックテスト向けの履歴データ要求。
- プロバイダーのストリーミング経路を利用したリアルタイム購読。
- このアダプターは市場データ用であり、注文ルーティングは行いません。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

プロバイダーのデータをチャート、市場データ保存、分析、調査、戦略テストに利用できます。

利用可能な銘柄、データ深度、取引権限、制限、サービス状況は Chainlink Data Streams、API プラン、接続口座の権限によって決まります。
