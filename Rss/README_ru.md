# Коннектор RSS
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **RSS** подключает StockSharp к сервису финансовых новостей и событийных данных. Он переводит данные и операции провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые подписки и рабочие процессы для разных площадок.

## Основные возможности

- Поддерживаемые адаптером рыночные данные: финансовые новости.
- Запросы исторических данных для графиков, анализа и тестирования стратегий.
- Адаптер предназначен для получения рыночных данных и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор позволяет использовать новости и события провайдера в мониторинге, аналитике, оповещениях и событийных стратегиях.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются RSS, тарифом API и правами подключённого счёта.
