# Settrade コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Settrade コネクター**は、Settrade Open API v2 を通じて StockSharp をタイの株式・デリバティブ市場へ接続します。REST と MQTT の市場データおよび証券取引機能を StockSharp メッセージモデルへ統合します。

## 主な機能

- 設定した SET 株式口座または TFEX デリバティブ口座で銘柄コードを直接検索。全銘柄一覧の一括取得には非対応。
- Level 1 と板のスナップショットおよび更新をリアルタイム取得。ティック取引購読には非対応。
- 対応期間の履歴ローソク足を取得し、その後 MQTT 更新を継続。
- 成行・指値注文と対応する TFEX 条件注文。株式口座のストップ注文は非対応。
- 有効期限、NVDR、アイスバーグ、ポジション、トリガーなど適用可能な Settrade 固有項目で変更・取消。
- スナップショット、非公開トピック、定期照合による口座、ポートフォリオ、ポジション、注文、取引情報。
- 本番／サンドボックスのエンドポイントを設定でき、機能に応じて認証情報、Broker ID、口座、種類、PIN が必要。
- 認証、MQTT トピック、形式は標準 StockSharp API の背後に隠蔽。

## 主な用途

Settrade 経由のタイ市場向け端末、ライブ戦略、注文管理、口座監視に利用できます。

銘柄、期間、板深度、口座機能、取引権限、制限は Settrade、口座種別、その権限によって決まります。
