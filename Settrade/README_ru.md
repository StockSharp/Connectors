# Коннектор Settrade
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **Settrade** подключает StockSharp к Settrade Open API v2 для тайских акций и деривативов. REST- и MQTT-сервисы рыночных данных и брокерских операций объединяются в модели сообщений StockSharp.

## Основные возможности

- Поиск заданного символа для настроенного счёта акций SET или деривативов TFEX; массовая загрузка каталога инструментов отсутствует.
- Котировки Level 1 и снимки и обновления стаканов в реальном времени; подписки на тиковые сделки не предоставляются.
- Исторические свечи с последующими MQTT-обновлениями для поддерживаемых интервалов.
- Рыночные и лимитные заявки, а также поддерживаемые условные заявки TFEX; стоп-заявки для акций недоступны.
- Изменение и отмена заявок с полями Settrade для срока действия, NVDR, айсберга, позиции и триггера, где применимо.
- Данные счёта, портфели, позиции, заявки и сделки через снимки, закрытые темы и периодическую сверку.
- Настраиваются production- и sandbox-адреса; при необходимости требуются ключи, Broker ID, счёт, его тип и торговый PIN.
- Аутентификация, MQTT-темы и форматы Settrade скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для терминалов тайского рынка, торговых роботов, управления заявками и мониторинга счетов через Settrade.

Доступные символы, интервалы свечей, глубина стакана, функции счёта, торговые права и лимиты запросов определяются Settrade, типом счёта и его разрешениями.
