# Коннектор TraderMade
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **TraderMade** подключает StockSharp к сервисам валютных и криптовалютных рыночных данных TraderMade. История REST и потоковые котировки WebSocket преобразуются в единую модель рыночных данных StockSharp.

## Основные возможности

- Формирование валютных пар из списка валют провайдера и настроенных валют котировки либо из явно заданного списка символов.
- Котировки покупки, продажи и средней цены Level 1 в реальном времени через потоковый API.
- Необязательные стаканы TraderLadder при наличии доступа и включённой настройке.
- Исторические свечи заданного таймфрейма через REST, включая необязательные криптовалютные данные за выходные.
- Раздельные ключи REST и streaming позволяют использовать только историю, только поток или оба режима.
- Свечные подписки конечны и историчны; текущие обновления свечей и подписки на тиковые сделки не поддерживаются.
- Коннектор предоставляет только рыночные данные: портфелей, балансов и торговых операций нет.
- Символы, транспорт и форматы TraderMade скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для валютных и криптовалютных панелей, мониторинга котировок, графиков, аналитики и исторического тестирования без брокерского исполнения.

Доступные пары, глубина TraderLadder, интервалы и история свечей, лимиты, данные выходных и потоковый доступ определяются TraderMade и тарифом API.
