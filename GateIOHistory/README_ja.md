# Gate.io 履歴データコネクター

**Gate.io 履歴データコネクター**は、Gate.io が公開する市場データアーカイブを StockSharp に取り込みます。現物およびデリバティブのデータセットを、保存、分析、再生に使える統一 StockSharp メッセージモデルへ変換します。

## 主な機能

- 現物、無期限先物、受渡先物市場の銘柄検索。
- 履歴ティック取引、インクリメンタル板情報、時間枠ローソク足。
- 市場データを体系的に補完するための日付範囲指定ダウンロード。
- ネイティブシンボルと市場区分を StockSharp の銘柄識別子へ対応付けます。
- 履歴データ専用のアダプターであり、リアルタイム購読や注文ルーティングは提供しません。
- Gate.io のアーカイブ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

チャート、分析、板研究、戦略バックテスト向けの暗号資産履歴データの準備に利用できます。

利用可能な銘柄、ファイル、日付、深度、ローソク足間隔は Gate.io が公開するデータセットによって決まります。
