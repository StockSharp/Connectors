# Коннектор исторических данных Gate.io

**Коннектор исторических данных Gate.io** загружает публичные архивы рыночных данных Gate.io в StockSharp. Он преобразует наборы данных спотового и срочного рынков в единую модель сообщений StockSharp для хранения, анализа и воспроизведения.

## Основные возможности

- Поиск инструментов спотового рынка, бессрочных и поставочных фьючерсов.
- Исторические тиковые сделки, инкрементальные стаканы и свечи заданного таймфрейма.
- Загрузка по диапазону дат для систематического пополнения рыночной истории.
- Нативные символы и варианты рынков сопоставляются с идентификаторами инструментов StockSharp.
- Адаптер предназначен для исторических данных и не предоставляет онлайн-подписки или выставление заявок.
- Форматы архивов Gate.io скрыты за стандартным API StockSharp.

## Для чего подходит

Используйте коннектор для подготовки криптовалютной истории для графиков, аналитики, исследования стаканов и тестирования стратегий.

Доступные инструменты, файлы, даты, глубина и интервалы свечей зависят от публичных наборов данных Gate.io.
