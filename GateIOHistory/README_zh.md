# Gate.io 历史数据连接器

**Gate.io 历史数据连接器**将 Gate.io 发布的市场数据归档导入 StockSharp。它把现货和衍生品数据集转换为统一的 StockSharp 消息模型，用于存储、分析和回放。

## 主要功能

- 发现现货、永续期货和交割期货市场的交易品种。
- 提供历史逐笔成交、增量订单簿和周期 K 线。
- 支持按日期范围下载，以系统化地回填市场数据。
- 将原生交易代码和市场类型映射为 StockSharp 交易品种标识符。
- 此适配器仅用于历史数据，不提供实时订阅或订单路由。
- Gate.io 的归档格式均封装在标准 StockSharp API 之后。

## 适用场景

适用于准备加密资产历史数据，以供图表、分析、订单簿研究和策略回测使用。

可用交易品种、文件、日期、深度和 K 线周期取决于 Gate.io 发布的公开数据集。
