# Коннектор CoinCatch
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор CoinCatch** связывает StockSharp со спотовым и срочным рынками CoinCatch. Параметр продукта выбирает спот, фьючерсы с маржой в USDT или фьючерсы с маржой в монете, а REST и WebSocket API предоставляют рыночные данные и авторизованную торговлю.

## Основные возможности

- Поиск инструментов выбранного продукта CoinCatch.
- Подписка на Level 1, стакан, тиковые сделки и свечи заданного таймфрейма.
- Загрузка исторических свечей с продолжением потоком WebSocket.
- Выставление лимитных и рыночных заявок, включая reduce-only для фьючерсов и post-only для лимитных заявок.
- Отмена отдельной заявки или всех заявок по инструменту.
- Загрузка балансов, позиций, открытых и исторических заявок и собственных сделок.
- Сверка приватного состояния с авторизацией по API-ключу, секрету и парольной фразе.

## Для чего подходит

Используйте коннектор для наблюдения за спотовым или фьючерсным рынком, получения истории свечей и автоматической торговли на CoinCatch. До подключения выберите продукт, а для приватных операций укажите учетные данные с нужными правами чтения или торговли.

Адаптер не предоставляет plan/trigger-заявки CoinCatch, айсберг-заявки и атомарную замену заявки. Стаканы передаются срезами, поток журнала заявок отсутствует. Необходимо учитывать правила инструментов, режим счета, права API и лимиты запросов биржи.
