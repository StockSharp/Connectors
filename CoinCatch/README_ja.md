# CoinCatch コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**CoinCatch コネクター**は、StockSharp を CoinCatch の現物・デリバティブ市場に接続します。商品設定で現物、USDT 証拠金先物、コイン証拠金先物を選択し、REST と WebSocket API から市場データおよび認証付き取引機能を利用します。

## 主な機能

- 選択した CoinCatch 商品の銘柄検索。
- Level 1、板情報、ティック約定、時間枠別ローソク足の購読。
- ヒストリカルローソク足の取得と WebSocket によるリアルタイム更新への継続。
- 指値・成行注文、先物の Reduce-only、指値注文の Post-only の送信。
- 個別注文または銘柄単位の全注文の取消。
- 残高、ポジション、現在・過去の注文、自身の約定の取得。
- API キー、シークレット、パスフレーズ認証によるプライベート状態の照合。

## 主な用途

CoinCatch の現物・先物市場監視、ローソク足履歴の取得、自動売買に適しています。接続前に商品を選び、プライベート操作には必要な参照・取引権限を持つ認証情報を設定してください。

CoinCatch のプラン注文やトリガー注文、アイスバーグ注文、アトミックな注文変更には対応しません。板情報はスナップショット形式で、注文ログ配信はありません。銘柄ルール、口座モード、API 権限、取引所のレート制限を順守する必要があります。
