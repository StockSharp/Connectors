# NovaDAX コネクター

[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**NovaDAX コネクター**は、StockSharp を NovaDAX の暗号資産スポット市場に接続します。ブラジルレアル建ての取引ペアに強い取引所であるため、ブラジルの暗号資産市場の監視、データ収集、自動売買に適しています。

## 主な機能

- 取引状態、価格と数量の精度、最小注文条件を含むスポット銘柄情報。
- Level 1 気配、Level 2 板情報、公開約定、OHLCV ローソク足履歴。
- Socket.IO によるティッカー、板情報、約定のリアルタイム配信。
- REST による市場スナップショット、直近約定、過去ローソク足。
- 残高、未約定・過去注文、注文状態、自己約定。
- 成行、指値、ストップ成行、ストップ指値注文と、個別または銘柄単位の取消。
- REST と Socket.IO の接続先、サブアカウント ID、Engine.IO バージョンを設定可能。

公開市場データに認証情報は不要です。ポートフォリオと取引機能には NovaDAX の API キーとシークレットが必要で、必要に応じてサブアカウント ID を指定できます。
