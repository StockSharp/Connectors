# Коннектор CoinSpot
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор CoinSpot** связывает StockSharp со спотовой криптовалютной биржей и брокером CoinSpot. Для рыночных данных, состояния счета и операций с заявками он использует публичный, торговый и приватный REST API CoinSpot.

## Основные возможности

- Поиск спотовых рынков CoinSpot и сведений об инструментах.
- Получение срезов Level 1, стакана и последних тиковых сделок.
- Обновление публичных подписок опросом REST API с настраиваемым интервалом.
- Выставление лимитных и рыночных заявок на покупку или продажу.
- Отмена отдельной заявки или группы подходящих открытых заявок.
- Загрузка балансов, состояния портфеля, открытых и исторических заявок и собственных сделок.
- Раздельная настройка публичного, торгового и приватного REST-адресов.

## Для чего подходит

Используйте коннектор для наблюдения за спотовым рынком CoinSpot и автоматической торговли через REST. Публичные данные доступны без авторизации; для операций со счетом и заявками требуются API-ключ и секрет CoinSpot с соответствующими правами.

У адаптера нет потока WebSocket; он не предоставляет свечи, исторические события Level 1 и исторические стаканы. Публичные обновления выполняются опросом, а история последних сделок ограничена ответом провайдера. Атомарная замена, условные, айсберг-, post-only- и GTD-заявки не поддерживаются.
