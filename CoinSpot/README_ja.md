# CoinSpot コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**CoinSpot コネクター**は、StockSharp を CoinSpot の暗号資産現物取引所・ブローカーに接続します。CoinSpot の公開、取引、読み取り専用プライベート REST API を使い、市場データ、口座状態、注文操作を提供します。

## 主な機能

- CoinSpot 現物市場と銘柄メタデータの検索。
- Level 1 ティッカー、板スナップショット、直近ティック約定の取得。
- 設定可能な間隔での REST ポーリングによる公開購読の更新。
- 指値・成行の買い注文と売り注文の送信。
- 個別注文または条件に一致する未約定注文群の取消。
- 残高、ポートフォリオ状態、現在・過去の注文、自身の約定の取得。
- 公開、取引、読み取り専用プライベート API エンドポイントの個別設定。

## 主な用途

CoinSpot 現物市場の監視と REST ベースの自動売買に適しています。公開市場データには認証が不要です。口座・注文機能には、適切な権限を持つ CoinSpot API キーとシークレットが必要です。

WebSocket 配信はなく、ローソク足、Level 1 履歴イベント、板履歴には対応しません。公開データはポーリングで更新され、直近約定の履歴範囲はプロバイダー応答に制限されます。アトミックな注文変更、条件付き、アイスバーグ、Post-only、GTD 注文は利用できません。
