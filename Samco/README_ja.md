# Samco コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Samco コネクター**は、Samco Trade API を通じて StockSharp をインドの証券・デリバティブ市場へ接続します。ブローカーの市場データと取引機能を統一された StockSharp メッセージモデルで提供します。

## 主な機能

- NSE、BSE、NFO、BFO、CDS、MCX、MFO で対応する株式、先物、オプションを検索。
- Samco フィードから Level 1、ティック取引、5 段階の板情報をリアルタイム取得。
- 履歴ローソク足を取得し、ストリーミングまたは REST ポーリングで更新を継続。
- 指値注文など対応注文の送信・変更・個別取消。原子的な一括取消には非対応。
- 資金枠、保有資産、ポジション、注文、取引を取得し、非公開状態を定期照合。
- 任意の WebSocket 市場データ、REST フォールバック、設定可能な間隔とエンドポイント。
- 有効な日次セッショントークンまたは Samco API 認証情報を使用し、ブローカーのセッション規則に従う。
- Samco 固有の識別子、セッション、形式は標準 StockSharp API の背後に隠蔽。

## 主な用途

Samco 口座へ接続するインド市場向け端末、ライブ戦略、ポートフォリオ監視、注文管理に利用できます。

銘柄範囲、5 段階の深度、履歴、取引権限、制限、セッション期間は Samco と接続口座によって決まります。
