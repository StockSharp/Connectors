# Коннектор Samco
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **Samco** подключает StockSharp к Samco Trade API для индийских ценных бумаг и деривативов. Рыночные и торговые сервисы брокера становятся доступны через единую модель сообщений StockSharp.

## Основные возможности

- Поиск поддерживаемых акций, фьючерсов и опционов на NSE, BSE, NFO, BFO, CDS, MCX и MFO.
- Котировки Level 1, тиковые сделки и пятиуровневые стаканы в реальном времени через поток Samco.
- Исторические свечи с последующими обновлениями через поток или REST-опрос.
- Отправка и изменение лимитных и других поддерживаемых брокером заявок, а также их отдельная отмена; атомарная групповая отмена недоступна.
- Лимиты портфеля, активы, позиции, заявки и сделки с периодической сверкой закрытого состояния.
- Необязательные потоковые данные WebSocket с резервным REST-опросом и настраиваемыми адресами сервисов.
- Для входа используется действующий дневной токен сессии либо ключ и секрет Samco с учётом правил сессии брокера.
- Идентификаторы, сессии и форматы Samco скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для терминалов индийского рынка, торговых роботов, мониторинга портфеля и управления заявками через счёт Samco.

Состав инструментов, пятиуровневая глубина, история, торговые разрешения, лимиты и срок жизни сессии определяются Samco и подключённым счётом.
