# OpenFIGI コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**OpenFIGI コネクター**は、StockSharp を金融商品識別子のマッピングおよび参照データサービスに接続します。プロバイダー固有の結果を統一された StockSharp 銘柄モデルへ変換するため、異なるデータソース間で一貫した銘柄識別子を利用できます。

## 主な機能

- 主な対象：世界の金融商品と識別子メタデータ。
- FIGI、ISIN、CUSIP、SEDOL、ティッカー、またはその他の OpenFIGI 識別子種別によるマッピング。
- 取引所コード、MIC、通貨、市場セクター、銘柄種別による検索と絞り込み。
- プロバイダーの参照データと識別子を含む標準化された StockSharp 銘柄メッセージ。
- このアダプターは読み取り専用で、価格ストリームや注文ルーティングは提供しません。
- プロバイダー固有の REST 通信、ページング、レート制御、応答形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

銘柄マスターデータの保守、識別子の補完、プロバイダー間の照合、および StockSharp ワークフローへの銘柄登録に利用できます。

利用可能なマッピング、検索結果、ページサイズ、制限、サービス状況は OpenFIGI と API キーの設定有無によって決まります。
