# Коннектор OpenFIGI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **OpenFIGI** подключает StockSharp к сервису сопоставления идентификаторов финансовых инструментов и справочных данных. Он переводит результаты провайдера в единую модель инструментов StockSharp, чтобы приложения могли использовать согласованные идентификаторы из разных источников данных.

## Основные возможности

- Типичные данные: глобальные финансовые инструменты и метаданные идентификаторов.
- Сопоставление по FIGI, ISIN, CUSIP, SEDOL, тикеру или другому типу идентификатора OpenFIGI.
- Поиск и фильтрация инструментов по коду биржи, MIC, валюте, сектору рынка и типу инструмента.
- Нормализованные сообщения StockSharp об инструментах со справочными данными и идентификаторами провайдера.
- Адаптер работает только на чтение: он не предоставляет потоки цен и не маршрутизирует заявки.
- REST-транспорт, постраничная загрузка, ограничение частоты запросов и форматы ответов провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для ведения справочника инструментов, обогащения идентификаторов, сверки данных разных провайдеров и подключения инструментов к рабочим процессам StockSharp.

Доступные сопоставления, результаты поиска, размеры страниц, лимиты запросов и доступность сервиса определяются OpenFIGI и наличием настроенного API-ключа.
