# Finage コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Finage コネクター**は、StockSharp を Finage の Forex 市場データサービスへ接続します。通貨商品向けの読み取り専用アダプターで、REST の参照・履歴データと、任意の WebSocket クォートストリームを組み合わせます。

## 主な機能

- 設定したシンボル一覧、またはプロバイダーの REST シンボル検索による通貨ペアの検索。
- REST による現在の最良買値・売値スナップショット。
- 専用ストリーミングトークンを設定した場合の、WebSocket による Level 1 買値・売値ライブ更新。
- REST による 1、5、10、15、30 分、1、2、4、6、8、12 時間、1 日、1 週間の過去ローソク足。
- REST 使用量を制御するためのリクエスト間隔と最大商品数の設定。
- 過去の Level 1 イベントとライブのローソク足更新には対応していません。
- ティック約定、板、発注、ポートフォリオデータ、口座操作には対応していません。

## 主な用途

Forex のウォッチリスト、クォート監視、チャート、調査、Finage のローソク足履歴に基づくバックテストに使用できます。

Finage の REST API キーが必要で、ライブクォートには別途ストリーミングトークンも必要です。シンボルの対象範囲、履歴の深さ、リアルタイムアクセス、リクエスト制限は契約中の Finage プランに依存します。
