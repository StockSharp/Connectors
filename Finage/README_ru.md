# Коннектор Finage
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **Finage** подключает StockSharp к сервисам валютных рыночных данных Finage. Это адаптер только для чтения, который объединяет справочные и исторические данные REST с необязательным потоком котировок WebSocket.

## Основные возможности

- Поиск валютных пар в настроенном списке символов или через поиск символов в REST API провайдера.
- Текущие снимки лучших цен покупки и продажи через REST.
- Обновления цен покупки и продажи Level 1 в реальном времени через WebSocket при наличии отдельного потокового токена.
- Исторические свечи через REST с интервалами 1, 5, 10, 15 и 30 минут; 1, 2, 4, 6, 8 и 12 часов; 1 день; 1 неделя.
- Настраиваемые интервал запросов и максимальное количество инструментов для контроля использования REST API.
- Исторические события Level 1 и обновления текущих свечей не поддерживаются.
- Тиковые сделки, стаканы, выставление заявок, портфельные данные и операции со счётом не поддерживаются.

## Для чего подходит

Используйте коннектор для валютных списков наблюдения, мониторинга котировок, построения графиков, исследований и тестирования стратегий на истории свечей Finage.

Для работы нужен REST API-ключ Finage, а для котировок в реальном времени — отдельный потоковый токен. Состав символов, глубина истории, доступ к real-time и лимиты запросов зависят от подключённого тарифа Finage.
