# Коннектор MAX Exchange

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор MAX Exchange** подключает StockSharp к спотовой бирже группы MaiCoin, ориентированной на рынок Тайваня. Он особенно полезен для криптовалютных пар с TWD и USDT.

## Основные возможности

- Получение списка спотовых инструментов, их статуса, точности и минимальных объёмов.
- Котировки Level 1, стаканы Level 2, публичные сделки и свечи OHLCV.
- Тикеры, стаканы, сделки и свечи в реальном времени через WebSocket.
- Исторические свечи и текущие снимки рынка через REST API v3.
- Балансы, открытые и исторические заявки и собственные сделки.
- Рыночные, лимитные, stop-market, stop-limit, post-only и IOC-заявки.
- Одиночная и групповая отмена; настраиваемые адреса REST и WebSocket.

## Для чего подходит

Используйте коннектор в торговых роботах, терминалах, сборщиках данных рынка TWD, системах мониторинга и управления заявками.

Публичные рыночные данные доступны без учётных данных. Для счёта и торговли нужны API-ключ и секрет MAX Exchange.
