# Bybit 历史数据连接器

**Bybit 历史数据连接器**将 Bybit 发布的市场数据归档导入 StockSharp。它把可下载的现货和衍生品数据规范化为标准 StockSharp 消息模型。

## 主要功能

- 发现现货、线性、反向和期权市场的交易品种。
- 获取受支持现货和衍生品的历史逐笔成交。
- 获取受支持市场和深度的历史增量订单簿数据。
- 支持按日期范围下载，适合批量回填和构建可重复使用的研究数据集。
- 此适配器仅用于历史数据，不提供实时订阅或订单路由。
- Bybit 的归档格式和市场标识符均封装在标准 StockSharp API 之后。

## 适用场景

适用于构建成交与订单簿历史，用于分析、市场回放和策略回测。

可用交易品种、日期、订单簿深度和文件取决于 Bybit 保留的公开数据集。
