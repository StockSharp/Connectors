# Коннектор исторических данных Bybit

**Коннектор исторических данных Bybit** загружает публичные архивы рыночных данных Bybit в StockSharp. Он преобразует доступные для скачивания данные по спотовым и срочным инструментам в стандартную модель сообщений StockSharp.

## Основные возможности

- Поиск инструментов спотового, линейного, инверсного и опционного рынков.
- Исторические тиковые сделки по поддерживаемым спотовым и срочным инструментам.
- Исторические инкрементальные стаканы для поддерживаемых рынков и глубины.
- Загрузка по диапазону дат для массового пополнения истории и воспроизводимых исследовательских наборов.
- Адаптер предназначен для исторических данных и не предоставляет онлайн-подписки или выставление заявок.
- Форматы архивов и рыночные идентификаторы Bybit скрыты за стандартным API StockSharp.

## Для чего подходит

Используйте коннектор для построения истории сделок и стаканов, аналитики, воспроизведения рынка и тестирования стратегий.

Доступные инструменты, даты, глубина стакана и файлы зависят от публичных наборов данных, сохраняемых Bybit.
