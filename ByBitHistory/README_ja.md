# Bybit 履歴データコネクター

**Bybit 履歴データコネクター**は、Bybit が公開する市場データアーカイブを StockSharp に取り込みます。現物およびデリバティブ銘柄のダウンロードデータを標準 StockSharp メッセージモデルへ正規化します。

## 主な機能

- 現物、リニア、インバース、オプション市場の銘柄検索。
- 対応する現物およびデリバティブ銘柄の履歴ティック取引。
- 対応市場と深度の履歴インクリメンタル板情報。
- 大規模な履歴補完と再現可能な研究用データセットに適した日付範囲指定ダウンロード。
- 履歴データ専用のアダプターであり、リアルタイム購読や注文ルーティングは提供しません。
- Bybit のアーカイブ形式と市場識別子は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

分析、市場再生、戦略バックテスト向けの取引履歴と板履歴の構築に利用できます。

利用可能な銘柄、日付、板深度、ファイルは Bybit が保持する公開データセットによって決まります。
