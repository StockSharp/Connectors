# Bit2Me コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Bit2Me コネクター**は、StockSharp をスペインのデジタル資産事業者が提供する現物取引プラットフォーム Bit2Me Pro に接続します。StockSharp の標準メッセージモデルを通じて、EUR 流動性を持つ暗号資産市場へ直接アクセスするシステムに適しています。

## 主な機能

- Bit2Me Pro の現物市場と、価格・数量・最小注文ルールの取得。
- Level 1 相場と Level 2 オーダーブックの REST スナップショット。
- WebSocket による公開約定と完全なオーダーブック更新のリアルタイム配信。
- Bit2Me が提供する時間間隔の過去約定と OHLCV ローソク足。
- 成行、指値、ストップリミット注文の送信。
- 注文の取消、および注文と約定の取得。
- ポートフォリオ残高と有効注文で拘束された資金の取得。
- テスト、ルーティング、インフラ変更に対応する REST と WebSocket アドレスの設定。

## 一般的な用途

Bit2Me Pro の現物銘柄を扱う取引ロボット、端末、データ収集、注文管理サービス、監視ツールで利用できます。

公開市場データに認証情報は不要です。取引と口座操作には、適切な権限を持つ Bit2Me API キーとシークレットが必要です。利用可能な市場、制限、口座機能は Bit2Me によって管理されます。
