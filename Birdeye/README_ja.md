# Birdeye コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Birdeye コネクター**は、StockSharp を Birdeye のオンチェーン暗号資産データ API に接続します。選択したブロックチェーンについて、トークン検索、現在の市場指標、OHLCV 履歴を提供します。既定のチェーンは Solana です。

## 主な機能

- 選択したチェーンのトークンを検索し、参照情報を取得。
- トークンアドレスによる検索の限定と、最低流動性フィルターの適用。
- Level 1 スナップショットの取得と REST ポーリングによる更新。
- 設定した履歴上限までの時間枠別ヒストリカルローソク足取得。
- 有料 WebSocket を利用した Level 1 とローソク足のリアルタイム更新。
- 米ドルまたはチェーンのネイティブ通貨による価格表示。
- Birdeye 対応時間枠の利用。1 分未満のローソク足は Solana のみ対応。

## 主な用途

Birdeye 対応ネットワークでのトークンスクリーニング、オンチェーン価格監視、OHLCV 履歴分析に適しています。購読前に、チェーン、API トークン、建値方式、必要に応じて検索フィルターを設定してください。

Birdeye は市場データプロバイダーのため、注文、ポートフォリオ、約定執行、板情報は提供しません。Level 1 の履歴イベントには対応せず、ストリーミングを無効にした場合、ローソク足購読は履歴の返却後に終了します。データ範囲、WebSocket 利用権限、リクエスト上限は Birdeye の API プランに依存します。
