# Коннектор Birdeye
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Birdeye** связывает StockSharp с API ончейн-данных Birdeye для криптовалют. Он предоставляет поиск токенов, текущие рыночные показатели и историю OHLCV для выбранного блокчейна; по умолчанию используется Solana.

## Основные возможности

- Поиск токенов и загрузка справочных данных для выбранной сети.
- Ограничение поиска адресом токена и фильтром минимальной ликвидности.
- Получение срезов Level 1 и их обновление опросом REST API.
- Загрузка исторических свечей заданного таймфрейма с учетом настроенного лимита.
- Платный WebSocket-режим для потоковых обновлений Level 1 и свечей.
- Представление цен в долларах США или нативной валюте сети.
- Работа с интервалами Birdeye; субминутные свечи доступны только для Solana.

## Для чего подходит

Используйте коннектор для отбора токенов, наблюдения за ончейн-ценами и анализа истории OHLCV в поддерживаемых Birdeye сетях. Перед подпиской задайте сеть, API-токен, валюту котирования и при необходимости фильтры поиска.

Birdeye является поставщиком рыночных данных, поэтому коннектор не поддерживает заявки, портфели, сделки и стакан. Исторические события Level 1 недоступны, а без потокового режима подписка на свечи завершается после выдачи истории. Состав данных, доступ к WebSocket и лимиты запросов зависят от тарифного плана Birdeye.
