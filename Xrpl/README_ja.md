# XRPL コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**XRPL コネクター**は、StockSharp を XRP Ledger 内蔵の分散型取引所へ接続します。設定した通貨ペア、台帳の板、成立した Offer、口座残高、署名済み取引を StockSharp メッセージへ変換します。

## 主な機能

- 設定した XRP と発行トークンのペアを検出し、任意で許可制 DEX ドメインを選択。
- Level 1 と設定可能な深度の板スナップショットを取得し、台帳更新に追随。
- 板変更から履歴・ライブのティック取引を生成し、台帳活動から期間別ローソク足を構築。
- 指値 Offer と価格保護付き IOC 成行 Offer、個別取消、変更、追跡対象の一括取消。
- 口座残高、未約定 Offer、注文状態、約定、手数料、取引状態を更新。
- 公開データには RPC と WebSocket のみ必要。取引にはクラシック口座アドレスと Family Seed が必要。
- 履歴は台帳走査上限に制限され、ライブスナップショットは設定したポーリング間隔を使用。
- XRPL の数量、発行体、署名、台帳シーケンス、手数料、イベントは標準 StockSharp API の背後に隠蔽。

## 主な用途

XRPL DEX 端末、台帳市場分析、履歴調査、口座監視、Offer の直接執行に利用できます。

ペア、板流動性、保存履歴、取引費用、確定性、許可ドメイン、エンドポイントは XRPL の状態と設定サービスに依存します。
