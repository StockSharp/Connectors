# Коннектор XRPL
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **XRPL** подключает StockSharp к децентрализованной бирже XRP Ledger. Настроенные валютные пары, книги заявок реестра, исполненные предложения, балансы счёта и подписанные транзакции преобразуются в сообщения StockSharp.

## Основные возможности

- Поиск настроенных пар XRP и выпущенных токенов с необязательным выбором домена permissioned DEX.
- Котировки Level 1 и снимки стакана настраиваемой глубины с обновлениями по реестру.
- Исторические и текущие тиковые сделки из изменений книг и построенные по активности реестра свечи.
- Лимитные предложения и защищённые по цене рыночные IOC-предложения, отдельная отмена, замена и отслеживаемая групповая отмена.
- Балансы счёта, открытые предложения, состояния заявок, исполнения, комиссии и статусы транзакций.
- Для публичных данных нужны только RPC- и WebSocket-адреса; для торговли — классический адрес счёта и family seed.
- Глубина истории ограничена лимитом сканирования реестров, а текущие снимки используют заданный интервал опроса.
- Суммы, эмитенты, подпись, последовательности реестров, комиссии и события XRPL скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для терминалов XRPL DEX, аналитики реестра, исторических исследований, мониторинга счёта и прямого размещения предложений.

Состав пар, ликвидность стакана, сохранённая история реестров, комиссии, финализация, доступ к разрешённым доменам и адресам зависят от состояния XRPL и настроенного сервиса.
