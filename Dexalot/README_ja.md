# Dexalot コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Dexalot コネクター**は、StockSharp を Avalanche ベースの Dexalot L1 にあるオンチェーン中央指値注文板へ接続します。公開 REST・WebSocket データと EVM コントラクト呼び出しを組み合わせ、現物取引と口座状態を扱います。

## 主な機能

- Dexalot の現物トークンペアの検索と参照データ取得。
- コントラクト読み取りによる Level 1・板スナップショットと、その後の WebSocket ライブ更新。過去の Level 1・板イベントには対応していません。
- WebSocket による約定・ローソク足ストリーム。プロバイダーが配信する履歴内で日時と件数を絞り込み、そのままライブ配信を継続できます。
- 5、15、30 分、1、4 時間、1 日のローソク足。
- post-only と設定可能な自己取引防止を含むオンチェーン指値・成行注文。
- 注文変更、個別取消、一括取消。アイスバーグ注文、絶対有効期限、一括ポジション決済には対応していません。
- REST、WebSocket、EVM RPC によるポートフォリオのトークン残高、注文・約定履歴、プライベート状態の照合。

## 主な用途

Dexalot の注文板とオンチェーン執行を必要とするリアルタイム現物戦略、取引端末、注文管理サービスに使用できます。

取引にはウォレットアドレスと秘密鍵が必要で、ネットワークの Gas 費用と確認待ち時間が発生します。利用可能なペア、ストリームの履歴範囲、API 制限、コントラクトの可用性、ファイナリティは Dexalot と選択したネットワークエンドポイントに依存します。
