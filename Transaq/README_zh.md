# Transaq 连接器

**Transaq 连接器**将 StockSharp 接入俄罗斯经纪商使用的 Transaq 交易服务器。它把服务器的 XML 命令和异步更新转换为统一的 StockSharp 消息模型。

## 主要功能

- 为股票、期货和期权发现交易品种、交易板块、市场及受支持的数据类型。
- 提供实时 Level 1 行情、逐笔成交、增量订单簿、K 线和新闻。
- 请求服务器支持的历史逐笔成交和 K 线。
- 支持标准、条件、止损、回购和协议订单流程，包括修改和撤销。
- 更新投资组合、限额、杠杆、资金、持仓、订单和自有成交。
- 支持生产和演示端点、代理、密码修改、心跳和串行命令处理。

## 适用场景

适用于经纪商终端、俄罗斯市场实时策略、订单管理、账户监控、图表和历史分析。

可用交易品种、历史、订单类型、账户字段和交易权限取决于 Transaq 服务器、经纪商配置及所连接账户。
