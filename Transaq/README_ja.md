# Transaq コネクター

**Transaq コネクター**は、StockSharp をロシアのブローカーが使用する Transaq 取引サーバーへ接続します。サーバーの XML コマンドと非同期更新を統一 StockSharp メッセージモデルへ変換します。

## 主な機能

- 株式、先物、オプション向けの銘柄、取引区分、市場、対応データ種別の検索。
- リアルタイム Level 1 クォート、ティック取引、インクリメンタル板情報、ローソク足、ニュース。
- サーバーが対応する履歴ティックおよびローソク足要求。
- 標準、条件付き、ストップ、レポ、相対取引注文。変更と取消を含みます。
- ポートフォリオ、制限、レバレッジ、資金、ポジション、注文、自己約定の更新。
- 本番・デモエンドポイント、プロキシ、パスワード変更、ハートビート、コマンドの逐次処理。

## 主な用途

ブローカー端末、ロシア市場のライブ戦略、注文管理、口座監視、チャート、履歴分析に利用できます。

利用可能な銘柄、履歴、注文種別、口座フィールド、取引権限は、Transaq サーバー、ブローカー設定、接続口座によって決まります。
