# Quidax コネクター

[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Quidax コネクター**は StockSharp を Quidax の現物取引市場に接続します。NGN をはじめとするアフリカの法定通貨建て暗号資産市場や、暗号資産同士のペアの監視と取引に適しています。

## 主な機能

- 通貨ペア、価格・数量精度、最小注文金額を含む現物銘柄の取得。
- Level 1 気配、Level 2 板情報、公開約定、履歴ローソク足。
- 設定可能な間隔の REST ポーリングによる継続的な市場データ購読。
- ウォレット残高、未約定・履歴注文、自己約定。
- 指値・成行注文、個別取消、条件付き一括取消。
- REST アドレス、口座またはサブアカウント ID、ポーリング間隔の設定。

公開市場データには認証情報は不要です。ポートフォリオと取引には Quidax のシークレットキーが必要です。既定のユーザー ID `me` はトークン所有者を示し、対応するサブアカウント ID に変更できます。
