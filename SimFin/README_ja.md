# SimFin コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**SimFin コネクター**は、SimFin の企業ファンダメンタルと日次価格履歴を StockSharp から読み取り専用で利用できるようにします。レコードを証券、Level 1 スナップショット、日足、専用のファンダメンタルメッセージへ変換します。

## 主な機能

- ティッカーまたは SimFin 企業 ID で企業と証券を検索。
- 最新の日次価格レコードを Level 1 スナップショットとして取得。
- 履歴の日次 OHLCV ローソク足。日中期間とライブ更新には非対応。
- 損益計算書、貸借対照表、キャッシュフロー、派生指標の対象を設定可能。
- 会計期間、日付範囲、標準化値または報告値、比率、最大件数を制御。
- 調査と履歴収集向けの有限 REST 購読のみで、ストリーミングはない。
- ティック取引、板、ニュース、ポートフォリオ、取引操作は提供しない。
- SimFin の認証、レート制御、応答形式は標準 StockSharp API の背後に隠蔽。

## 主な用途

ファンダメンタルスクリーニング、企業価値分析、日次価格分析、別コネクターの約定・日中データと組み合わせるバックテストに利用できます。

企業範囲、項目、履歴、更新頻度、制限、アクセスは SimFin と接続した API プランによって決まります。
