# Коннектор SimFin
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **SimFin** предоставляет StockSharp доступ только для чтения к фундаментальным данным компаний и дневной истории цен SimFin. Записи провайдера преобразуются в инструменты, снимки Level 1, дневные свечи и специальный тип фундаментальных сообщений StockSharp.

## Основные возможности

- Поиск компаний и инструментов по тикеру или идентификатору компании SimFin.
- Последняя доступная дневная цена в виде снимка Level 1.
- Исторические дневные свечи OHLCV; внутридневные интервалы и потоковые обновления свечей не поддерживаются.
- Фундаментальная отчётность с настраиваемыми наборами отчёта о прибылях и убытках, баланса, денежных потоков и производных показателей.
- Настройки финансового периода, диапазона дат, стандартизированных или исходных данных, коэффициентов и максимума записей.
- Только конечные REST-подписки для исследований и истории; потокового транспорта нет.
- Тиковые сделки, стаканы, новости, портфели и торговые операции не предоставляются.
- Аутентификация, ограничение частоты и форматы SimFin скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для фундаментального скрининга, оценки компаний, анализа дневных цен и тестирования стратегий совместно с данными исполнения или внутридневными данными другого коннектора.

Состав компаний, поля отчётности, история, частота обновления, лимиты и доступ определяются SimFin и подключённым тарифом API.
