# Коннектор SSI
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **SSI** подключает StockSharp к SSI FastConnect API v3 для рынка ценных бумаг Вьетнама. Он переводит рыночные данные и брокерские операции SSI в единую модель сообщений StockSharp.

## Основные возможности

- Поиск ценных бумаг и индексов HOSE, HNX и UPCOM, включая акции и поддерживаемые фьючерсы.
- Котировки Level 1, тиковые сделки и стаканы в реальном времени с начальными REST-снимками, когда они доступны.
- Исторические свечи заданного таймфрейма с последующими потоковыми обновлениями для поддерживаемых интервалов.
- Регистрация, замена и отмена отдельных заявок, включая специальные условия заявок SSI.
- Поиск счетов, балансы, позиции, заявки и исполнения с потоковыми обновлениями и периодической сверкой.
- Настраиваемые REST- и WebSocket-адреса и интервал опроса портфеля.
- Требуются учётные данные FastConnect; торговля также зависит от Client ID, счёта, закрытого RSA-ключа и актуального OTP.
- Сессии, форматы и потоковые темы SSI скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для терминалов вьетнамского рынка, торговых роботов, сервисов управления заявками и систем мониторинга с прямым доступом к брокеру SSI.

Доступные инструменты, глубина истории, торговые разрешения, лимиты запросов и доступность сервиса определяются SSI и правами подключённого счёта FastConnect.
