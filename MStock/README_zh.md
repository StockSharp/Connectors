# m.Stock 连接器
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**m.Stock 连接器**将 StockSharp 接入印度经纪商及其支持的交易所板块。它把提供商特有的数据和操作转换为统一的 StockSharp 消息模型，使应用程序能够在不同场所使用相同的订阅和工作流程。

## 主要功能

- 典型覆盖范围：印度股票、指数、期货、期权、货币衍生品、基金和债券。
- 发现交易品种并获取提供商参考数据。
- 适配器支持的市场数据：Level 1 行情、逐笔成交、订单簿、K 线。
- 请求历史 K 线，用于图表、分析和策略回测。
- 提供商支持的订单提交、修改、撤销和成交处理流程。
- 投资组合、余额、持仓、订单和成交更新。
- 通过提供商的流式传输通道进行实时订阅。
- 提供商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

适用于需要直接访问 m.Stock 账户的实时策略、交易终端、订单管理服务和监控工具。

可用交易品种、交易所板块、数据深度、交易权限、请求限制和服务可用性由 m.Stock、相关交易所及所连接账户的权限决定。
