# Коннектор SET Market Data
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **SET Market Data** подключает StockSharp к профессиональному сервису рыночных данных и аналитики. Он переводит данные и операции провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые подписки и рабочие процессы для разных площадок.

## Основные возможности

- Типичные рынки и инструменты: акции.
- Поиск инструментов и получение справочных данных провайдера.
- Поддерживаемые провайдером рыночные данные, сведения о компаниях, отчётность, раскрытия и справочная информация.
- Поддерживаемые адаптером рыночные данные: котировки Level 1 и стаканы заявок.
- Подписки реального времени через потоковый транспорт провайдера.
- Адаптер предназначен для доступа к данным и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для наполнения графиков и хранилищ, аналитики, исследований и тестирования стратегий на данных провайдера.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются SET Market Data, тарифом API и правами подключённого счёта.
