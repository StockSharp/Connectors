# J-Quants 连接器
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**J-Quants 连接器**通过 J-Quants API V2 为 StockSharp 提供日本市场参考数据和历史数据。它是面向研究的只读 REST 适配器，不用于实时行情流或交易。

## 主要功能

- 发现日本上市股票、期货和期权并获取参考数据，包括衍生品的标的、行权价、期权类型和到期日。
- 根据最新可用日线生成一次性 Level 1 消息；这并不是实时报价订阅。
- 获取股票历史逐笔成交；期货和期权不提供逐笔历史。
- 获取股票历史 K 线，支持 1、5、15、30 分钟，1 小时和 1 日周期。
- 获取期货和期权的历史日线。
- 可配置 REST 调用间隔和最大分页深度。
- 不支持订单簿、实时更新、下单、投资组合数据或账户操作。

## 适用场景

该连接器适用于日本金融品种目录、历史研究、图表、数据准备，以及基于 J-Quants 数据集的策略回测。

使用时需要 J-Quants V2 API 密钥。可用接口、品种、日期范围、分页和请求频率取决于订阅的 J-Quants 套餐；Level 1 数值来自日线，不应视为实时最佳买卖价。
