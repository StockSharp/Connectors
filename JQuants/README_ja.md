# J-Quants コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**J-Quants コネクター**は、J-Quants API V2 を通じて日本市場の参照データと履歴データを StockSharp に取り込みます。調査向けの読み取り専用 REST アダプターであり、リアルタイム配信や取引には使用しません。

## 主な機能

- 日本の上場株式、先物、オプションの検索と参照データ取得。デリバティブの原資産、権利行使価格、オプション種別、満期も含みます。
- 最新の利用可能な日足から生成する 1 回限りの Level 1 メッセージ。ライブクォート購読ではありません。
- 株式の過去ティック約定。先物とオプションのティック履歴には対応していません。
- 株式の 1、5、15、30 分、1 時間、1 日の過去ローソク足。
- 先物とオプションの日足履歴。
- REST 呼び出し間隔と最大ページ取得数を設定可能。
- 板、ライブ更新、発注、ポートフォリオデータ、口座操作には対応していません。

## 主な用途

日本の商品カタログ、履歴調査、チャート、データ準備、J-Quants データセットを使ったバックテストに使用できます。

J-Quants V2 API キーが必要です。利用可能なエンドポイント、商品、期間、ページ取得、リクエスト頻度は契約プランに依存します。Level 1 の値は日足に基づくため、リアルタイムの最良買値・売値として扱わないでください。
