# Коннектор FINRA
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **FINRA** подключает StockSharp к сервису финансовых данных и справочной информации. Он переводит данные провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые подписки и рабочие процессы для разных источников данных.

## Основные возможности

- Типичные рынки и инструменты: акции и справочные данные об эмитентах.
- Поиск инструментов и получение справочных данных провайдера.
- Поддерживаемые провайдером рыночные данные, сведения о компаниях, отчётность, раскрытия и справочная информация.
- Поддерживаемые адаптером рыночные данные: котировки Level 1.
- Запросы исторических данных для графиков, анализа и тестирования стратегий.
- Адаптер предназначен для доступа к данным и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для справочников инструментов, мониторинга раскрытий, исследования эмитентов, задач комплаенса и исторического анализа.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются FINRA, тарифом API и правами подключённого счёта.
