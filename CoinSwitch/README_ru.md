# Коннектор CoinSwitch
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор CoinSwitch** связывает StockSharp с API CoinSwitch PRO. Параметр продукта выбирает спотовые рынки INR или USDT, бессрочные фьючерсы с маржой в USDT либо закрытый beta-интерфейс HFT-опционов.

## Основные возможности

- Поиск инструментов выбранного продукта CoinSwitch.
- Подписка на Level 1, стакан, тиковые сделки и свечи заданного таймфрейма.
- Загрузка истории свечей и получение обновлений WebSocket там, где их поддерживают продукт и интервал.
- Выставление лимитных заявок на споте, лимитных, рыночных и stop-market заявок на фьючерсах, а также лимитных или рыночных HFT-заявок на опционах.
- Параметр reduce-only для поддерживаемых заявок на деривативы и доступные режимы времени действия для HFT-опционов.
- Отмена отдельной заявки или группы подходящих заявок.
- Загрузка балансов, позиций, открытых и исторических заявок и собственных сделок.

## Для чего подходит

Используйте коннектор для наблюдения за CoinSwitch PRO и автоматической торговли в одном выбранном продуктовом режиме. Для приватных операций нужны API-ключ и секрет Ed25519 с подходящими правами; для опционов дополнительно требуется доступ к закрытой HFT beta CoinSwitch.

Возможности зависят от продукта: на споте принимаются только лимитные заявки, условный ввод реализован только для фьючерсов как stop-market, а опционные свечи не передаются через WebSocket. Атомарная замена, айсберг- и GTD-заявки, инкрементальные стаканы и журнал заявок не поддерживаются. Действуют права и лимиты CoinSwitch.
