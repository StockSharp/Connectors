# IIFL 连接器
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**IIFL 连接器**通过 IIFL Markets Open API 将 StockSharp 接入印度交易所行情和券商业务，并把 IIFL 的 REST 与 MQTT 服务转换为标准 StockSharp 消息模型。

## 主要功能

- 在 NSE、BSE、股票衍生品、货币衍生品和商品市场板块中发现品种，包括股票、指数、期货和期权。
- 通过 REST 和官方 MQTT 数据流获取 Level 1 快照、五档订单簿及实时逐笔成交更新。
- 获取历史 K 线并通过轮询更新活动 K 线，支持 1、5、10、15、30 分钟，1 小时，1 日，1 周和 1 月周期。
- 支持市价单、限价单、止损限价单和止损市价单，以及改单和单笔撤单；不支持批量撤单。
- 支持 IIFL 专用产品和订单复杂类型、触发价、披露数量、市场价格保护、算法标识和客户标签。
- 通过 REST 快照和私有 MQTT 更新获取资金、持仓资产、头寸、订单状态及成交。
- 可配置 MQTT 流式传输，以及对私有状态和活动 K 线的 REST 轮询。

## 适用场景

该连接器适用于印度市场交易终端、实时策略、订单管理服务、投资组合监控和基于 K 线的分析。

连接时需要 IIFL 应用凭据、客户标识，以及每日授权流程或现有会话令牌。可用品种、行情权限、订单功能、交易时段和请求限制取决于 IIFL 账户及交易所板块。
