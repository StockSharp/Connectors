# IIFL コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**IIFL コネクター**は、IIFL Markets Open API を通じて StockSharp をインド取引所の市場データと証券取引サービスへ接続します。IIFL の REST・MQTT サービスを標準の StockSharp メッセージモデルへ変換します。

## 主な機能

- NSE、BSE、株式デリバティブ、通貨デリバティブ、商品市場の各セグメントにおける、株式、指数、先物、オプションの検索。
- REST と公式 MQTT ストリームによる Level 1 スナップショット、5 階層の板、ライブティック更新。
- 1、5、10、15、30 分、1 時間、1 日、1 週間、1 か月の過去ローソク足とポーリング更新。
- 成行、指値、ストップ指値、ストップ成行注文と、注文変更・個別取消。一括取消には対応していません。
- IIFL 固有の商品区分と注文複雑度、トリガー価格、開示数量、市場価格保護、アルゴリズム ID、クライアントタグ。
- REST スナップショットとプライベート MQTT 更新による資金、保有銘柄、ポジション、注文状態、約定。
- MQTT ストリーミングと、プライベート状態・アクティブなローソク足の REST ポーリングを設定可能。

## 主な用途

インド市場向け取引端末、リアルタイム戦略、注文管理サービス、ポートフォリオ監視、ローソク足分析に使用できます。

接続には IIFL アプリケーション認証情報、クライアント ID、および日次認証フローまたは既存のセッショントークンが必要です。利用可能な商品、市場データ権限、注文機能、取引時間、リクエスト制限は IIFL 口座と取引所セグメントに依存します。
