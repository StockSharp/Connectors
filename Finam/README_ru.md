# Коннектор Finam Trade API

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Finam Trade API** подключает приложения StockSharp к брокерским счетам и рыночным данным Финама. Инструменты, котировки, заявки, сделки и состояние портфеля преобразуются в единую модель сообщений StockSharp.

## Основные возможности

- Поиск доступных через Финам акций, облигаций, валют, фондов, фьючерсов и опционов.
- Котировки Level 1, стаканы, публичные сделки и свечи по временным интервалам.
- Запрос исторических свечей и подписки на рыночные данные в реальном времени.
- Выставление рыночных, лимитных, стоп- и стоп-лимитных заявок, а также снятие заявок.
- Обновления состояний заявок, собственных сделок, денежных остатков и позиций.
- Автоматический обмен API-секрета на короткоживущий токен сессии.
- Настраиваемые адреса REST и WebSocket для совместимых шлюзов и тестовых сред.

## Для чего подходит

Коннектор можно использовать в торговых роботах, терминалах, системах контроля портфеля и сервисах управления заявками, которым нужен единый интерфейс StockSharp для работы с Финамом.

Для подключения требуется секрет Finam Trade API. Можно явно указать торговый счёт либо разрешить коннектору выбрать первый счёт, доступный токену. Инструменты задаются в формате Финама `тикер@MIC`. Доступные рынки, глубина истории, потоковые данные, торговые права и лимиты запросов зависят от подключённого счёта и условий сервиса Финама.
