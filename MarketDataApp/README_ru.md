# Коннектор MarketData.app
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **MarketData.app** подключает StockSharp к профессиональному сервису рыночных данных. Он переводит данные провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые запросы и рабочие процессы для разных источников данных.

## Основные возможности

- Типичные рынки и инструменты: акции, ETF, опционы, индексы и фонды.
- Поиск инструментов, включая цепочки опционов, и получение справочных данных провайдера.
- Поддерживаемые адаптером рыночные данные: снимки котировок Level 1 и свечи.
- Запросы исторических свечей для графиков, анализа и тестирования стратегий; сервис не предоставляет свечи по опционам.
- Адаптер предназначен для рыночных данных и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для наполнения графиков и хранилищ рыночных данных, поиска инструментов и опционов, аналитики, исследований и тестирования стратегий на данных провайдера.

Доступные инструменты, глубина истории, корректировки, лимиты запросов, права на данные и доступность сервиса определяются MarketData.app и подключённым тарифом API.
