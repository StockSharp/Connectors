# MarketData.app コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**MarketData.app コネクター**は、StockSharp をプロ向け市場データサービスに接続します。プロバイダー固有のデータを統一された StockSharp メッセージモデルへ変換するため、異なるデータソースでも同じ要求とワークフローを利用できます。

## 主な機能

- 主な対象：株式、ETF、オプション、指数、ファンド。
- オプションチェーンを含む銘柄検索とプロバイダーの参照データ。
- アダプターが対応する市場データ：Level 1 クォートのスナップショットとローソク足。
- チャート、分析、バックテスト向けの履歴ローソク足要求。サービスはオプションのローソク足を提供しません。
- このアダプターは市場データ用であり、注文ルーティングは行いません。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

チャート、銘柄・オプション検索、市場データ保存、分析、調査、およびプロバイダーデータによる戦略テストに利用できます。

利用可能な銘柄、履歴の深さ、調整、制限、データ権限、サービス状況は MarketData.app と接続する API プランによって決まります。
