# Coincall コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Coincall コネクター**は、StockSharp を Coincall のオプション・先物市場に接続します。商品設定で対象デリバティブを選択し、REST からスナップショットと履歴、認証済み WebSocket から市場およびプライベートのライブ更新を取得します。

## 主な機能

- Coincall のオプションまたは先物銘柄の検索。
- Level 1、板情報、ティック約定、時間枠別ローソク足の購読。
- 直近約定とヒストリカルローソク足を取得し、その後 WebSocket ライブ更新へ継続。
- 指値、成行、トリガー価格付き条件注文と、対応する GTC、IOC、FOK、Post-only、Reduce-only パラメーターの送信。
- 個別注文の変更・取消と、条件に一致する注文群の取消。
- 残高、ポジション、現在・過去の注文、自身の約定の取得。
- 設定可能な間隔でのプライベート状態照合。

## 主な用途

Coincall デリバティブの監視と、オプションまたは先物の自動売買に適しています。REST の銘柄検索とスナップショットは認証情報なしでも接続できますが、WebSocket 配信とすべてのプライベート操作には API キーとシークレットが必要です。

アダプターの各インスタンスでは一つの商品領域のみを選択します。アイスバーグ注文と絶対日時による期限指定には対応せず、板情報はスナップショット形式で注文ログもありません。利用可能な銘柄、取引権限、API 上限は Coincall によって決まります。
