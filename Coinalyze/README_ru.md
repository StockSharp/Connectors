# Коннектор Coinalyze
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Coinalyze** связывает StockSharp с API аналитики криптовалютного рынка Coinalyze. Он преобразует исторические цены и показатели деривативов в стандартные свечи StockSharp для фьючерсных или спотовых инструментов.

## Основные возможности

- Выбор фьючерсных или спотовых инструментов и необязательное ограничение поиска биржей.
- Загрузка исторических свечей цены, открытого интереса, ставки финансирования, ликвидаций или соотношения длинных и коротких позиций.
- Использование таймфреймов, поддерживаемых API Coinalyze.
- Необязательное преобразование открытого интереса и ликвидаций в доллары США.
- Настройка лимита истории до 2 000 записей на запрос.
- Авторизация запросов с помощью API-токена Coinalyze.

## Для чего подходит

Используйте коннектор для бэктестинга, исследования деривативов и сравнения исторических метрик Coinalyze. До подписки выберите тип рынка и метрику свечи, а для сужения набора инструментов задайте фильтр биржи.

Адаптер работает только с историей через REST. Он не предоставляет обновления свечей в реальном времени, Level 1, тиковые сделки, стакан, портфели и исполнение заявок. Доступные символы, интервалы, глубина истории и частота запросов определяются API Coinalyze.
