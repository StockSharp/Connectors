# Coinalyze コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Coinalyze コネクター**は、StockSharp を Coinalyze の暗号資産市場分析 API に接続します。先物または現物銘柄の履歴価格とデリバティブ指標を、標準 StockSharp 時間枠別ローソク足として扱います。

## 主な機能

- 先物または現物銘柄の選択と、必要に応じた取引所による検索範囲の限定。
- 価格、建玉、資金調達率、清算、ロング・ショート比のヒストリカルローソク足取得。
- Coinalyze API が対応する時間枠の利用。
- 建玉と清算の値を任意で米ドル換算。
- 1 リクエストあたり最大 2,000 件の履歴上限を設定。
- Coinalyze API トークンによるリクエスト認証。

## 主な用途

バックテスト、デリバティブ調査、Coinalyze 履歴指標の比較分析に適しています。購読前に市場種別とローソク足指標を選び、対象を絞る場合は取引所フィルターを指定してください。

このアダプターは REST による履歴専用です。ローソク足のライブ更新、Level 1、ティック約定、板情報、ポートフォリオ、注文執行には対応しません。利用可能なシンボル、時間枠、履歴深度、リクエスト頻度は Coinalyze API によって決まります。
