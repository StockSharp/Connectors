# Bitalong コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Bitalong コネクター**は、StockSharp を旧デジタル資産取引所向け統合に接続します。 プロバイダー固有のデータと操作を統一された StockSharp メッセージモデルへ変換するため、異なる取引先でも同じ購読とワークフローを利用できます。

上流サービスはすでに利用できない可能性があります。この統合は既存システムとの互換性、保守、および完全なコネクター実装の学習用として保持されています。

## 主な機能

- 主な対象：デジタル資産、現物市場。
- 銘柄検索とプロバイダーの参照データ。
- アダプターが対応する市場データ：Level 1 クォート、ティック取引、板情報。
- プロバイダーが対応する注文送信と約定処理。
- ポートフォリオ、残高、ポジション、約定状態の更新。
- プロバイダーのストリーミング経路を利用したリアルタイム購読。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

既存統合の保守、または市場データ、取引、プロトコル詳細を StockSharp に対応付ける方法を学ぶ実践的なソースコードとして利用できます。

実運用前に、上流 API と必要な接続先が現在も利用可能か確認してください。
