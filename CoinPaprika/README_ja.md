# CoinPaprika コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**CoinPaprika コネクター**は、StockSharp を CoinPaprika の暗号資産市場データ API に接続します。グローバルなコイン参照情報、または選択した取引所の市場情報に加え、ティッカースナップショットと OHLCV 履歴を提供します。

## 主な機能

- CoinPaprika のコインをグローバルに検索、または設定した取引所の銘柄に限定。
- ティッカーとローソク足要求で使う建値通貨の選択。
- 価格、24 時間出来高、変化率、提供される市場状態を含む Level 1 スナップショットの取得。
- 設定可能な間隔での REST ポーリングによる Level 1 更新。
- 時間枠別 OHLCV ヒストリカルローソク足の取得。
- トークンなしの無料 API、またはトークン付きプロ向けエンドポイントと拡張権限の利用。
- 履歴応答を設定可能な最大 366 件に制限。

## 主な用途

暗号資産の参照情報、簡易的な価格監視、OHLCV 履歴調査に適しています。データ要求前にグローバルまたは取引所別の検索範囲と建値通貨を設定してください。

CoinPaprika はデータ集約サービスであり、取引執行の場ではありません。注文、ポートフォリオ、ティック約定、板情報には対応しません。Level 1 の履歴イベントとローソク足のライブ更新も利用できません。日中足履歴、対象範囲、応答件数、レート制限は CoinPaprika の API プランとトークンに依存します。
