# Коннектор CoinPaprika
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор CoinPaprika** связывает StockSharp с API криптовалютных рыночных данных CoinPaprika. Он предоставляет глобальные справочные данные по монетам или рынки выбранной биржи, а также срезы тикеров и исторические свечи OHLCV.

## Основные возможности

- Глобальный поиск монет CoinPaprika или ограничение инструментов настроенной биржей.
- Выбор валюты котирования для запросов тикеров и свечей.
- Получение срезов Level 1 с ценой, суточным объемом, изменением и состоянием рынка, если эти поля доступны.
- Обновление Level 1 опросом REST API с настраиваемым интервалом.
- Загрузка исторических свечей OHLCV заданного таймфрейма.
- Работа с бесплатным API без токена или настройка токена профессионального API с расширенными правами.
- Ограничение ответа историей до 366 записей.

## Для чего подходит

Используйте коннектор для справочных данных по криптовалютам, легкого мониторинга цен и исследования истории OHLCV. Перед запросом выберите глобальный поиск или конкретную биржу и задайте валюту котирования.

CoinPaprika является агрегатором данных, а не торговой площадкой. Адаптер не предоставляет заявки, портфели, тиковые сделки и стакан. Исторические события Level 1 и обновления свечей в реальном времени недоступны. Внутридневная история, охват, размер ответа и лимиты запросов зависят от тарифного плана и токена CoinPaprika.
