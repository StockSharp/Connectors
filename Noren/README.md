# Noren Protocol

`StockSharp.Noren` contains the shared Noren protocol implementation used by StockSharp connectors for brokers and venues based on the Noren OMS API.

This package provides common REST, WebSocket, market-data, transaction, and order-condition infrastructure. It is not a standalone connector: use a provider-specific package such as `StockSharp.Shoonya` or `StockSharp.Zebu` to connect to a trading account.
