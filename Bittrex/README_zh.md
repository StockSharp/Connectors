# Bittrex 连接器
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Bittrex 连接器**将 StockSharp 接入保留的旧版数字资产交易所集成。 它把提供商特有的数据和操作转换为统一的 StockSharp 消息模型，使应用程序能够在不同场所使用相同的订阅和工作流程。

上游服务可能已不可用。保留此集成是为了兼容现有系统、维护旧项目以及学习完整连接器的实现方式。

## 主要功能

- 典型覆盖范围：数字资产。
- 发现交易品种并获取提供商参考数据。
- 适配器支持的市场数据：Level 1 行情、逐笔成交、订单簿、K 线。
- 提供商支持的订单提交和成交处理流程。
- 投资组合、余额、持仓和成交状态更新。
- 通过提供商的流式传输通道进行实时订阅。
- 提供商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于维护现有集成，也可作为学习如何将市场数据、交易和协议细节映射到 StockSharp 的完整源代码示例。

用于实际系统前，请确认上游 API 和所需连接地址仍然可用。
