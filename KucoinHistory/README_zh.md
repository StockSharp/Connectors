# KuCoin 历史数据连接器

**KuCoin 历史数据连接器**将 KuCoin 发布的市场数据归档导入 StockSharp。它把可下载的现货和期货数据规范化为统一的 StockSharp 消息模型。

## 主要功能

- 发现现货和期货市场的交易品种并获取参考数据。
- 提供历史逐笔成交、订单簿和周期 K 线。
- 支持按日期范围下载，以可重复的方式回填市场数据存储。
- 将交易所代码和市场板块映射为 StockSharp 交易品种标识符。
- 此适配器仅用于历史数据，不提供实时订阅或订单路由。
- KuCoin 的归档传输和文件格式均封装在标准 StockSharp API 之后。

## 适用场景

适用于准备 KuCoin 历史数据，以供图表、分析、市场回放和策略回测使用。

可用交易品种、文件、日期、深度和 K 线周期取决于 KuCoin 保留的公开数据集。
