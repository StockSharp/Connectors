# Коннектор исторических данных KuCoin

**Коннектор исторических данных KuCoin** загружает публичные архивы рыночных данных KuCoin в StockSharp. Он преобразует доступные для скачивания данные спотового и фьючерсного рынков в единую модель сообщений StockSharp.

## Основные возможности

- Поиск инструментов и справочные данные для спотового и фьючерсного рынков.
- Исторические тиковые сделки, стаканы и свечи заданного таймфрейма.
- Загрузка по диапазону дат для воспроизводимого пополнения хранилища рыночных данных.
- Биржевые символы и сегменты рынка сопоставляются с идентификаторами инструментов StockSharp.
- Адаптер предназначен для исторических данных и не предоставляет онлайн-подписки или выставление заявок.
- Транспорт и форматы архивов KuCoin скрыты за стандартным API StockSharp.

## Для чего подходит

Используйте коннектор для подготовки истории KuCoin для графиков, аналитики, воспроизведения рынка и тестирования стратегий.

Доступные инструменты, файлы, даты, глубина и интервалы свечей зависят от публичных наборов данных, сохраняемых KuCoin.
