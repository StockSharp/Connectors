# KuCoin 履歴データコネクター

**KuCoin 履歴データコネクター**は、KuCoin が公開する市場データアーカイブを StockSharp に取り込みます。ダウンロード可能な現物および先物データを統一 StockSharp メッセージモデルへ正規化します。

## 主な機能

- 現物および先物市場の銘柄検索と参照データ。
- 履歴ティック取引、板情報、時間枠ローソク足。
- 市場データストレージを再現可能な形で補完する日付範囲指定ダウンロード。
- 取引所シンボルと市場区分を StockSharp の銘柄識別子へ対応付けます。
- 履歴データ専用のアダプターであり、リアルタイム購読や注文ルーティングは提供しません。
- KuCoin のアーカイブ転送とファイル形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

チャート、分析、市場再生、戦略バックテスト向けの KuCoin 履歴データの準備に利用できます。

利用可能な銘柄、ファイル、日付、深度、ローソク足間隔は KuCoin が保持する公開データセットによって決まります。
