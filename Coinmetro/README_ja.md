# Coinmetro コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Coinmetro コネクター**は、StockSharp を Coinmetro 暗号資産現物取引所に接続します。銘柄、口座、注文、ローソク足の REST エンドポイントと、市場およびプライベート活動の WebSocket 更新を組み合わせ、ライブ環境とデモ環境を個別に利用できます。

## 主な機能

- Coinmetro 現物銘柄と取引制約の検索。
- WebSocket による Level 1、板情報、ティック約定のライブ購読。
- 1 分、5 分、30 分、4 時間、日足のヒストリカルローソク足取得。
- 対応する GTC、IOC、FOK、GTD パラメーター付き指値・成行注文の送信。
- 個別注文または条件に一致する未約定注文群の取消。
- 残高、現在・過去の注文、自身の約定の取得。
- 設定可能なライブ・デモ用 REST および WebSocket エンドポイントの切替。

## 主な用途

Coinmetro 現物市場の監視、ローソク足履歴の取得、自動売買に適しています。ライブ環境のプライベート操作には必要な権限を持つアクセストークンを設定してください。デモモードは別の公開エンドポイントを使い、デモトークンを自動取得できます。

ローソク足は履歴専用で、ライブ更新には継続しません。アトミックな注文変更、条件付き、アイスバーグ、Post-only 注文には対応せず、板情報は StockSharp 差分ではなくスナップショットとして公開されます。戦略設計ではプライベート状態の照合間隔と API レート制限を考慮してください。
