# Коннектор KyberSwap
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **KyberSwap** подключает StockSharp к KyberSwap Aggregator API v1 и сетям EVM. Он представляет настроенные пары токенов как инструменты StockSharp, вычисляет исполнимые котировки по маршрутам агрегатора и отправляет подписанные ончейн-свопы.

## Основные возможности

- Поиск настроенных пар токенов и загрузка метаданных в сетях Ethereum, Optimism, BNB Chain, Polygon, Base, Arbitrum, Avalanche и Linea.
- Котировки покупки и продажи Level 1, рассчитанные по исполнимым маршрутам агрегатора для настраиваемого пробного объёма.
- Периодический REST-опрос активных подписок Level 1; исторические события котировок и потоковый транспорт недоступны.
- Немедленные рыночные свопы с локальной подписью и отправкой через EVM JSON-RPC, настраиваемым проскальзыванием и автоматическим разрешением токенов.
- Балансы токенов кошелька и обновления портфеля через запросы к блокчейну.
- Отслеживание отправленных коннектором свопов по хешу транзакции до получения EVM-квитанции об успехе или ошибке.
- Тиковые сделки, стаканы, свечи, лимитные заявки, а также замена и отмена уже отправленных транзакций не поддерживаются.

## Для чего подходит

Используйте коннектор для мониторинга DEX-котировок с учётом маршрутов и автоматических рыночных свопов в поддерживаемых сетях EVM.

Котировки можно запрашивать без торговых учётных данных, но для исполнения нужны кошелёк, приватный ключ и рабочий RPC-узел. На результат каждого свопа влияют определения токенов, ликвидность маршрута, разрешения, стоимость газа, проскальзывание, задержка квитанции, лимиты API и состояние сети.
