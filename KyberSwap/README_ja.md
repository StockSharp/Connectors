# KyberSwap コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**KyberSwap コネクター**は、StockSharp を KyberSwap Aggregator API v1 と EVM ネットワークへ接続します。設定したトークンペアを StockSharp 商品として公開し、アグリゲーターのルートから約定可能なクォートを算出して、署名済みオンチェーンスワップを送信します。

## 主な機能

- Ethereum、Optimism、BNB Chain、Polygon、Base、Arbitrum、Avalanche、Linea 上で、設定済みトークンペアの検索とメタデータ取得。
- 設定可能な試算数量に対し、約定可能なアグリゲータールートから算出する Level 1 買値・売値。
- アクティブな Level 1 購読を REST で定期ポーリング。過去のクォートイベントとストリーミング転送には対応していません。
- ローカル署名して EVM JSON-RPC から送信する即時成行スワップ。許容スリッページと自動トークン承認を設定できます。
- チェーン呼び出しによるウォレットのトークン残高とポートフォリオ更新。
- コネクターが送信したスワップをトランザクションハッシュで追跡し、EVM レシートが成功または失敗を確定するまで監視。
- ティック約定、板、ローソク足、指値注文、送信済みトランザクションの変更・取消には対応していません。

## 主な用途

対応 EVM ネットワークで、ルートを考慮した DEX クォート監視と成行スワップの自動化に使用できます。

クォート照会には取引認証情報は不要ですが、実行にはウォレット、秘密鍵、稼働中の RPC エンドポイントが必要です。トークン定義、ルート流動性、承認、Gas 費用、スリッページ、レシート待ち時間、API 制限、ネットワーク状態が各スワップの結果に影響します。
