# Pendle コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Pendle コネクター**は、StockSharp をオンチェーン利回り取引プロトコルに接続します。プロトコルデータとウォレット操作を統一された StockSharp メッセージモデルへ変換するため、Pendle 市場で標準の購読とトランザクションワークフローを利用できます。

## 主な機能

- 主な対象：オンチェーン利回り資産、プリンシパルトークン、イールドトークン、Pendle 市場。
- 銘柄検索とプロトコルの参照データ。
- アダプターが対応する市場データ：Level 1 クォートとローソク足。
- チャート、分析、戦略ワークフロー向けの履歴ローソク足要求と継続的な市場データ更新。
- 必要なトークン承認を含む、プロバイダー対応のトークン変換とブロックチェーントランザクション送信。
- ウォレットのポートフォリオ、残高、ポジション、約定状態の更新。
- プロトコル固有の HTTP／RPC 通信、ウォレットトランザクション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

利回り市場の監視、ライブ戦略、ウォレット状態を考慮する取引ツール、および Pendle で見積り取得や変換を実行するサービスに利用できます。

利用可能なネットワーク、市場、トークン、見積り、取引機能、手数料、サービス状況は Pendle、設定した API／RPC エンドポイント、現在のチェーン状況、ウォレット権限によって決まります。
