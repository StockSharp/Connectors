# Коннектор SEC EDGAR
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **SEC EDGAR** предоставляет StockSharp доступ только для чтения к официальной отчётности Комиссии по ценным бумагам и биржам США. Эмитенты, документы и факты XBRL преобразуются в инструменты, новости и специальный тип фундаментальных сообщений StockSharp.

## Основные возможности

- Поиск компаний по тикеру или CIK через каталог тикеров SEC.
- Получение документов как новостей StockSharp, включая свежие подачи и настраиваемое число исторических файлов.
- Фильтрация форм, например 10-K, 10-Q, 8-K, 20-F, 40-F и 6-K.
- Факты XBRL по компаниям с фильтрами дат и количества записей через тип данных Company Facts.
- Конечные REST-запросы для исторической загрузки и периодического обновления; push-поток не открывается.
- API-ключ не нужен, но политика SEC требует идентифицирующий User-Agent и соблюдение интервала запросов.
- Котировки, сделки, стаканы, свечи, портфели и торговые операции не предоставляются.
- Адреса SEC, CIK, исторические файлы и форматы ответов скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга отчётности, фундаментальных исследований, отбора эмитентов и наборов данных, объединяющих раскрытия SEC с рыночными данными другого коннектора.

Состав и оперативность данных определяются публикациями SEC. Частота запросов, число исторических файлов и фактов, а также фильтр форм задаются настройками адаптера и правилами доступа SEC.
