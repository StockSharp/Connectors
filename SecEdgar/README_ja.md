# SEC EDGAR コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**SEC EDGAR コネクター**は、米国証券取引委員会の公式提出データを StockSharp から読み取り専用で利用できるようにします。発行体、提出書類、XBRL 企業ファクトを証券、ニュース、専用のファンダメンタルメッセージへ変換します。

## 主な機能

- SEC の企業ティッカーカタログを使い、ティッカーまたは CIK で企業を検索。
- 最近の提出と設定可能な件数の履歴ファイルを StockSharp ニュースとして取得。
- 10-K、10-Q、8-K、20-F、40-F、6-K などのフォームで絞り込み。
- Company Facts データ型を通じ、日付と件数で絞った XBRL 企業ファクトを取得。
- 履歴収集や定期更新向けの有限 REST リクエストであり、プッシュストリームは開かない。
- API キーは不要だが、SEC 方針により識別可能な User-Agent と適切なリクエスト間隔が必要。
- 価格、取引、板、ローソク足、ポートフォリオ、注文機能は提供しない。
- SEC エンドポイント、CIK、履歴ファイル、応答形式は標準 StockSharp API の背後に隠蔽。

## 主な用途

提出書類の監視、ファンダメンタル調査、発行体スクリーニング、SEC 開示と別コネクターの市場データを組み合わせるデータセットに利用できます。

対象範囲と更新時期は SEC の公開内容に依存し、間隔、履歴ファイル数、ファクト数、フォームフィルターは設定と SEC のアクセス方針で決まります。
