# DexScreener コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**DexScreener コネクター**は、DexScreener の公開 REST API を通じて、複数チェーンの分散型取引所における取引ペア分析を StockSharp に取り込みます。読み取り専用の市場データアダプターであり、API 認証情報は不要です。

## 主な機能

- チェーン ID、トークンアドレス、正確なペアアドレス、または自由文によるペア検索。StockSharp のスキップ件数と取得件数も指定できます。
- 最新の USD 価格とネイティブトークン価格、24 時間出来高と価格変化、流動性、取引状態を含む Level 1 スナップショット。
- アクティブな Level 1 購読を REST で定期更新。ポーリング間隔は設定可能で、既定値は 30 秒です。
- DexScreener がインデックスするブロックチェーンと流動性プールを対象とします。
- API キーやプライベート口座セッションを必要としない公開アクセス。
- 過去の Level 1 イベントおよびリアルタイムのストリーミング転送には対応していません。
- ティック約定、板、ローソク足、発注、ポートフォリオデータ、口座操作には対応していません。

## 主な用途

DEX ペアの探索、ウォッチリスト、流動性スクリーニング、集約市場指標を定期更新するダッシュボードに使用できます。

これは注文執行用コネクターではなく、バックテスト向けのイベント履歴も提供しません。ペアの対象範囲、利用可能な項目、データ鮮度、リクエスト制限は DexScreener と各分散型取引所に依存します。
