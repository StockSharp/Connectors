# Коннектор DexScreener
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **DexScreener** загружает в StockSharp аналитику по торговым парам децентрализованных бирж из разных блокчейнов через публичный REST API DexScreener. Это адаптер рыночных данных только для чтения, которому не нужны API-ключи.

## Основные возможности

- Поиск пар по идентификатору сети, адресу токена, точному адресу пары или текстовому запросу с учётом ограничений StockSharp по пропуску и количеству результатов.
- Снимки Level 1 с последней ценой в долларах США и нативном токене, объёмом и изменением цены за 24 часа, ликвидностью и состоянием торгов.
- Периодическое обновление активных подписок Level 1 через REST; интервал опроса настраивается и по умолчанию равен 30 секундам.
- Работа с сетями и пулами ликвидности, которые индексирует DexScreener.
- Публичный доступ без API-ключа и приватной сессии счёта.
- Отсутствие исторических событий Level 1 и потокового транспорта реального времени.
- Тиковые сделки, стаканы, свечи, выставление заявок, портфельные данные и операции со счётом не поддерживаются.

## Для чего подходит

Используйте коннектор для поиска DEX-пар, списков наблюдения, отбора по ликвидности и панелей, которым достаточно периодически обновляемых агрегированных рыночных показателей.

Это не торговый коннектор и не источник событийной истории для тестирования стратегий. Состав пар, доступность полей, актуальность данных и лимиты запросов определяются DexScreener и соответствующими децентрализованными площадками.
