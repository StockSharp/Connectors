# Binance 履歴データコネクター

**Binance 履歴データコネクター**は、Binance が公開する市場データアーカイブを StockSharp に取り込みます。取引所のファイルと参照データを統一された StockSharp メッセージモデルへ変換し、一貫した保存、分析、再生を可能にします。

## 主な機能

- デジタル資産の現物市場とデリバティブ市場を対象。
- 銘柄検索とコントラクトの参照データ。
- 履歴 Level 1 クォート、ティック取引、板情報、時間枠ローソク足。
- 市場データストレージを自動補完するための日付範囲指定ダウンロード。
- 履歴データ専用のアダプターであり、リアルタイム購読や注文ルーティングは提供しません。
- Binance のアーカイブ形式と識別子は標準 StockSharp API の背後で正規化されます。

## 主な用途

ローカルストレージの構築、履歴系列の欠損補完、調査および戦略バックテスト用データの準備に利用できます。

利用可能な銘柄、ファイル、期間、データ粒度は Binance が公開するアーカイブによって決まります。
