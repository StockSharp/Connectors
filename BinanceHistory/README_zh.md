# Binance 历史数据连接器

**Binance 历史数据连接器**将 Binance 发布的市场数据归档导入 StockSharp。它把交易所文件和参考数据转换为统一的 StockSharp 消息模型，便于一致地存储、分析和回放。

## 主要功能

- 覆盖数字资产现货和衍生品市场。
- 发现交易品种并获取合约参考数据。
- 提供历史 Level 1 行情、逐笔成交、订单簿和周期 K 线。
- 支持按日期范围下载，便于自动补充市场数据存储。
- 此适配器仅用于历史数据，不提供实时订阅或订单路由。
- Binance 的归档格式和标识符均通过标准 StockSharp API 进行规范化。

## 适用场景

适用于填充本地存储、修复历史序列缺口，以及为研究和策略回测准备数据。

可用交易品种、文件、日期范围和数据粒度取决于 Binance 发布的归档。
