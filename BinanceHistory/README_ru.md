# Коннектор исторических данных Binance

**Коннектор исторических данных Binance** загружает публичные архивы рыночных данных Binance в StockSharp. Он преобразует биржевые файлы и справочные данные в единую модель сообщений StockSharp для последовательного хранения, анализа и воспроизведения.

## Основные возможности

- Поддержка спотовых и срочных рынков цифровых активов.
- Поиск инструментов и получение параметров контрактов.
- Исторические котировки Level 1, тиковые сделки, стаканы и свечи заданного таймфрейма.
- Загрузка по диапазону дат для автоматического пополнения хранилища рыночных данных.
- Адаптер предназначен для исторических данных и не предоставляет онлайн-подписки или выставление заявок.
- Форматы архивов и идентификаторы Binance нормализуются стандартным API StockSharp.

## Для чего подходит

Используйте коннектор для наполнения локального хранилища, восстановления пропусков в истории, исследований и тестирования стратегий.

Доступные инструменты, файлы, диапазоны дат и детализация зависят от архивов, публикуемых Binance.
