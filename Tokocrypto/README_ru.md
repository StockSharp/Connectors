# Коннектор Tokocrypto

[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Tokocrypto** подключает StockSharp к основному спотовому рынку MAIN биржи Tokocrypto. Он подходит для торговли криптовалютами на индонезийском рынке и для получения данных Tokocrypto в единой модели сообщений StockSharp.

## Основные возможности

- Загрузка спотовых инструментов MAIN с шагами цены и объёма и ограничениями минимального ордера.
- Котировки Level 1, стаканы Level 2, публичные сделки и свечи OHLCV.
- Потоковые тикеры, частичные стаканы, сделки и свечи через WebSocket.
- Исторические свечи и актуальные снимки рынка через публичный REST API.
- Спотовые балансы, активные и исторические заявки и история собственных сделок.
- Рыночные, лимитные, стоп-рыночные, стоп-лимитные, post-only, IOC и FOK заявки.
- Отмена отдельных и групп заявок; адреса account REST, market-data REST и WebSocket задаются в настройках.

## Где применять

Коннектор можно использовать в торговых роботах, терминалах, сборщиках маркет-данных, системах мониторинга и управления заявками для спотовых инструментов Tokocrypto.

Публичные рыночные данные доступны без авторизации. Для работы со счётом и торговли нужны API-ключ и секрет Tokocrypto.
