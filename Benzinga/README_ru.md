# Коннектор Benzinga
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

Коннектор **Benzinga** подключает StockSharp к сервису финансовых новостей и событийных данных. Он переводит данные и операции провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые подписки и рабочие процессы для разных площадок.

## Основные возможности

- Типичные рынки и инструменты: акции, фьючерсы, опционы, фонды и ETF, индексы.
- Поиск инструментов и получение справочных данных провайдера.
- Поддерживаемые адаптером рыночные данные: котировки Level 1, свечи и финансовые новости.
- Запросы исторических данных для графиков, анализа и тестирования стратегий.
- Подписки реального времени через потоковый транспорт провайдера.
- Адаптер предназначен для получения рыночных данных и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор позволяет использовать новости и события провайдера в мониторинге, аналитике, оповещениях и событийных стратегиях.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются Benzinga, тарифом API и правами подключённого счёта.
