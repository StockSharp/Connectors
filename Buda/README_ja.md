# Buda コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Buda コネクター**は、StockSharp を Buda.com の暗号資産現物取引所に接続します。公開市場データは認証情報なしで利用でき、認証付き REST 操作には API キーとシークレットを使用します。

## 主な機能

- Buda が提供する現物銘柄の検索。
- Level 1 気配、板情報、ティック約定の購読。
- 公開 WebSocket 更新と REST スナップショットおよび状態照合の併用。
- 指値・成行注文の送信と、個別または一括での注文取消。
- 残高、ポートフォリオ状態、現在・過去の注文、自身の約定の取得。
- 設定可能なポーリング間隔によるプライベート状態の照合。

## 主な用途

Buda 現物市場のリアルタイム監視と、StockSharp からの認証付き取引に適しています。公開データのみを使う場合は認証情報が不要です。注文と口座情報には、必要な権限を持つ Buda API キーとシークレットが必要です。

ローソク足と注文ログ配信には対応せず、板情報は差分ではなくスナップショットとして提供されます。注文のアトミックな変更はできないため、戦略側で既存注文の取消と新規注文を別々に行う必要があります。取引所の権限設定とレート制限が適用されます。
