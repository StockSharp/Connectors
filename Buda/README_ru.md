# Коннектор Buda
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Buda** связывает StockSharp со спотовой криптовалютной биржей Buda.com. Публичные рыночные данные доступны без учетных данных, а для авторизованных REST-операций используются API-ключ и секрет.

## Основные возможности

- Поиск спотовых инструментов, доступных на Buda.
- Подписка на котировки Level 1, стакан и тиковые сделки.
- Совмещение публичных обновлений WebSocket со срезами и сверкой через REST.
- Выставление лимитных и рыночных заявок, отмена одной заявки или группы заявок.
- Загрузка балансов, состояния портфеля, активных и исторических заявок и собственных сделок.
- Периодическая сверка приватного состояния с настраиваемым интервалом.

## Для чего подходит

Используйте коннектор для наблюдения за спотовым рынком Buda в реальном времени и авторизованной торговли из StockSharp. Для публичных данных учетные данные не нужны; для заявок и информации по счету требуются API-ключ и секрет Buda с необходимыми правами.

Адаптер не предоставляет свечи и поток журнала заявок, а стаканы передаются срезами, а не инкрементами. Атомарная замена заявки не поддерживается: стратегии нужно отдельно отменить старую и выставить новую. Действуют разрешения и лимиты запросов биржи.
