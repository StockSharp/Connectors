# Buda 连接器
[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Buda 连接器**将 StockSharp 接入 Buda.com 加密货币现货交易所。公开市场数据无需凭据即可使用；经过身份验证的 REST 操作则使用 API 密钥和密钥口令。

## 主要功能

- 发现 Buda 提供的现货交易品种。
- 订阅 Level 1 行情、市场深度和逐笔成交。
- 将公开 WebSocket 更新与 REST 快照及状态校准结合使用。
- 提交限价单和市价单，并取消单个订单或一组订单。
- 加载余额、投资组合状态、活动及历史订单和自身成交。
- 按可配置的轮询间隔校准私有状态。

## 适用场景

该连接器适合通过 StockSharp 实时监控 Buda 现货市场并进行认证交易。只使用公开数据时无需凭据；订单和账户工作流需要具备相应权限的 Buda API 密钥和密钥口令。

适配器不提供 K 线或订单日志数据流，订单簿以快照而非增量形式发送。它不支持原子改单，因此策略需要分别撤销原订单并提交新订单。交易所权限和请求速率限制仍然适用。
