# Chainflip コネクター
[English](README.md) | [Русский](README_ru.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md)

**Chainflip コネクター**は、StockSharp をクロスチェーン流動性ネットワーク Chainflip に接続します。公開されている State Chain とスワップサービスのデータを利用し、任意のウォレット設定により StockSharp の取引モデルからクロスチェーンスワップを送信できます。

## 主な機能

- Chainflip 対応プールと資産の検索。
- プール状態と約定から生成された Level 1、プール深度、取引データの取得。
- State Chain、見積サービス、Ethereum、Arbitrum の各エンドポイント設定。
- 見積の取得と、保護条件付きクロスチェーンスワップとしての成行注文送信。
- 送信済みスワップの追跡と、ポートフォリオメッセージによるウォレット残高の提供。
- 対応チェーン上の資産ごとの送付先アドレス設定。

## 主な用途

Chainflip の流動性監視や、設定済みウォレットからの即時クロスチェーンスワップに適しています。公開市場データには署名鍵が不要ですが、実行にはウォレットアドレス、秘密鍵、送付先アドレス、利用可能なチェーンエンドポイントが必要です。

これはプロトコル連携であり、中央集権型取引所の注文インターフェイスではありません。ローソク足、指値・条件付き注文、板に残る注文には対応しません。スワップトランザクションの送信後は、取消、変更、一括取消ができません。ネットワーク手数料、ファイナリティ、流動性、スリッページ、各チェーンの稼働状況が実行に影響します。
