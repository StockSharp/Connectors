# Коннектор Chainflip
[English](README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [Português](README_pt.md) | [日本語](README_ja.md)

**Коннектор Chainflip** связывает StockSharp с кроссчейн-сетью ликвидности Chainflip. Он объединяет публичные данные State Chain и сервиса обмена с необязательной настройкой кошелька для отправки кроссчейн-свопов через транзакционную модель StockSharp.

## Основные возможности

- Поиск поддерживаемых пулов и активов Chainflip.
- Получение Level 1, глубины пулов и сделок, сформированных из состояния пулов и исполнений.
- Настройка адресов State Chain, сервиса котировок, Ethereum и Arbitrum.
- Запрос котировки и отправка рыночной заявки как защищенного кроссчейн-свопа.
- Отслеживание отправленных свопов и представление балансов кошелька сообщениями портфеля.
- Настройка адресов назначения для активов в поддерживаемых сетях.

## Для чего подходит

Используйте коннектор для наблюдения за ликвидностью Chainflip или выполнения немедленных кроссчейн-свопов из настроенного кошелька. Для публичных рыночных данных ключ подписи не нужен; для исполнения требуются адрес кошелька, закрытый ключ, адреса назначения и доступные сетевые узлы.

Это интеграция с протоколом, а не интерфейс заявок централизованной биржи. Адаптер не предоставляет свечи, лимитные, условные или стоящие в книге заявки. После отправки транзакции своп нельзя отменить, заменить или включить в групповую отмену. На результат влияют комиссии сети, финальность, ликвидность, проскальзывание и доступность блокчейнов.
